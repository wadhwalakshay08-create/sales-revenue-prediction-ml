# Sales Revenue Prediction using Machine Learning

## About the Project

This project uses Machine Learning to predict sales revenue based on marketing campaign data and business-related features.

The model takes inputs such as advertising spend, product price, discount rate, market reach, impressions, click-through rate, competition index, seasonality, campaign duration, customer lifetime value, product category, customer segment, and marketing channel.

## Features

* Sales revenue prediction using Machine Learning
* User input-based predictions
* Numerical and categorical features
* RandomizedSearchCV for model hyperparameter tuning
* Pandas and NumPy for data handling

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

## Input Features

* Ad Spend
* Price

* Impressions

* Competition Index

* Customer Lifetime Value

* Customer Segment

## How to Run

1. Clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells in order.
5. Enter the required feature values to predict sales revenue.
